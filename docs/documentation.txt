Masked Face Recognition System 

Architecture & Methodology Documentation 

 

1. Project Title 

Adaptive Periocular-Based Masked Face Recognition Using RetinaFace and InsightFace (IR-50 + ArcFace) 

 

2. Problem Statement 

Traditional face recognition systems rely on complete facial features for identity verification. However, when a person wears a face mask, a significant portion of the face—including the nose, mouth, and jawline—is occluded, resulting in a considerable decline in recognition accuracy. 

The objective of this project is to develop a robust masked face recognition system that accurately identifies individuals by leveraging periocular features (eye region) whenever a mask is detected, while using full-face recognition for unmasked individuals. 

 

3. Objective 

The proposed system aims to: 

Detect human faces in an input image.  

Perform automatic face alignment.  

Detect whether the face is masked.  

Perform adaptive periocular cropping for masked faces.  

Generate discriminative facial embeddings using InsightFace.  

Compare embeddings with a stored database.  

Identify the person with high accuracy even under facial occlusion.

6. System Components 

6.1 Face Detection 

The system uses RetinaFace for detecting faces within an image. 

Responsibilities: 

Detect human faces  

Estimate facial landmarks  

Handle multiple faces  

Detect faces under different poses  

Improve localization accuracy  

Output: 

Bounding Box  

Five Facial Landmarks  

 

6.2 Face Alignment 

RetinaFace also estimates five facial landmarks. 

These include: 

Left Eye  

Right Eye  

Nose Tip  

Left Mouth Corner  

Right Mouth Corner  

Using these landmarks, the face is aligned to a canonical orientation before feature extraction. 

Benefits: 

Removes rotation  

Reduces pose variation  

Improves embedding consistency  

 

6.3 Mask Detection 

The aligned face is passed through a mask detection module. 

Output: 

Mask Present  

No Mask  

This module determines which recognition pipeline should be used. 

 

6.4 Adaptive Periocular Cropping 

If a mask is detected, the system extracts only the periocular region. 

The cropped region includes: 

Eyes  

Eyebrows  

Upper Nose Bridge  

The crop size is dynamically adjusted based on facial landmarks obtained from RetinaFace. 

Advantages: 

Eliminates occluded regions  

Focuses on discriminative eye features  

Improves recognition performance under mask occlusion  

 

6.5 Feature Extraction 

Feature extraction is performed using InsightFace. 

Configuration: 

Backbone: IR-50  

Pretrained ArcFace Weights  

The network converts an image into a fixed-length feature vector. 

Output: 

512-dimensional embedding. 

Example: 

[0.12, -0.43, 0.85, ..., 0.31] 

Each embedding uniquely represents the facial identity. 

 

6.6 Feature Database 

Each registered individual has stored embeddings generated during enrollment. 

Example: 

Database 
 
Person A 
Embedding A 
 
Person B 
Embedding B 
 
Person C 
Embedding C 

These embeddings serve as templates during recognition. 

 

6.7 Face Matching 

During recognition: 

Generate embedding for input image.  

Compare embedding with all stored embeddings.  

Compute cosine similarity.  

Select highest similarity score.  

Apply threshold.  

Decision: 

If similarity ≥ threshold 

→ Identity Recognized 

Else 

→ Unknown Person
